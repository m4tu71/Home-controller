# Home Controller v1.0.1（未公開候補）

v1.0.0からのGoセキュリティ更新です。版番号は1.0.1へ更新済みですが、正式候補commit・tag・配布物/checksumはまだ確定していません。
v1.0.0のtagと公開済み添付物は保持します。v1.0.0の記録は[旧Release notes](v1.0.0.md)を参照してください。

## 変更点

- config / Backend / controller-daemonの最低Go版を1.22.2から1.27.3へ更新し、標準ライブラリの既知脆弱性に対処。
- daemonの間接依存golang.org/x/sysをv0.19.0からv0.44.0へ更新。
- 使用するGo配布物のLICENSE/PATENTSとx/sysの第三者noticeを更新。
- Go source/binaryの脆弱性検査を[開発手順](../DEVELOPMENT.md#goの確認とbuild)と[配布手順](../RELEASING.md)へ追加。

HTTP API・保存形式・IR動作やFrontend/Picoの機能変更はありません。
VERSIONとFrontend package/lockの版は1.0.1です。Webの版表示・asset名とPico program versionはVERSIONを参照するため、正式候補生成時に1.0.1として再buildします。

## ローカル検証（2026-11-05）

版番号更新前の同じGo変更について、Go1.27.3/govulncheck v1.9.0で以下を確認しました。

| 対象 | 結果・限界 |
|---|---|
| Go3moduleのtest / vet | 成功 |
| Linux amd64 / arm64のsource解析 | 3module × 2arch、JSON finding0件 |
| 生成したBackend / daemonのbinary解析 | 2binary × 2arch、Go1.27.3のmetadataとJSON finding0件 |
| amd64隔離smoke | 新Go binaryと既存v1.0.0 Webを組み合わせた生成fixtureで6項目成功。v1.0.1 archiveの検査ではない |
| notice | 新Go/x/sysのLICENSE/PATENTSと照合。npm runtime依存は変更なし |

これらは未commitのローカル検証です。正式v1.0.1配布物のbuild/梱包・checksum・smokeはcommit後に別途実施します。
arm64の実行再検証は今回対象外です。新候補の実設置・Browser・家電動作・Pico書込みも未実施です。

## 既知制約と残件

v1.0.0の機能上の制約は継続します。認証なしの単一ローカル運用者向けで、APIをインターネットへ直接公開しないでください。
RAWは38kHz、codeはPANASONIC_40、captureはraw_samples専用です。送信成功は家電の実状態を保証しません。
JavaScriptの500kB超chunk警告の最適化、heat/dry運転、auto内部mode/実測温度等の未確認事項も継続します。

残件はレビュー/commit、clean候補のbuild/梱包と監査・checksumの再確認、公開tag/commit・配布物の対応付け、運用者の公開判断と公開後のdownload照合です。
